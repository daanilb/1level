# Probability & Statistics from Scratch: Restaurant Tips Analysis

Мини-проект по применению теории вероятностей и математической статистики
на практике. Все ключевые формулы (среднее, дисперсия, ковариация,
корреляция, условная вероятность, Z-оценка, демонстрация Центральной
предельной теоремы) реализованы **вручную**, без
`numpy`/`pandas`/`statistics`.

## Датасет

Использован классический датасет **tips** (чаевые в ресторане),
244 наблюдения, 7 признаков:

| Колонка      | Описание                        |
| ------------ | ------------------------------- |
| `total_bill` | сумма счёта, $                  |
| `tip`        | сумма чаевых, $                 |
| `sex`        | пол клиента                     |
| `smoker`     | курит ли клиент (Yes/No)        |
| `day`        | день недели                     |
| `time`       | время (Lunch/Dinner)            |
| `size`       | размер компании (число человек) |

Источник: [seaborn-data / tips.csv](https://github.com/mwaskom/seaborn-data/blob/master/tips.csv)
(копия лежит в `data/tips.csv`).

## Что именно посчитано (и какая тема теории вероятностей за этим стоит)

1. **Базовые числовые характеристики случайной величины**
   (мат ожидание, выборочная дисперсия,
   стандартное отклонение, медиана, мода) — для `total_bill`, `tip`, `tip_pct` (процент чаевых от счёта).

2. **Закон распределения дискретной случайной величины** —
   эмпирическая (частотная) вероятность P(X) для категориальных признаков
   (`day`, `smoker`, `sex`, `time`)

3. **Условная вероятность и проверка независимости событий** —
   сравнение P(smoker=Yes) с P(smoker=Yes | day=Sat)

4. **Ковариация и корреляция Пирсона** между `total_bill` и `tip`.

5. **Z-оценка (стандартизация) и правило трёх сигм** —
   поиск потенциальных выбросов в сумме счёта.

6. **Демонстрация Центральной предельной теоремы (ЦПТ)** —
   1000 симуляций случайных выборок размера 30 из `total_bill`!

## Как запустить

```bash
git clone https://github.com/<ваш-username>/<название-репозитория>.git
cd <название-репозитория>
pip install -r requirements.txt
python src/analyze.py
```
